ESSENTIALS — Bureau office · Atelier design · Linework CAD · Utilities

QUICK START
  • Simplest: open  index.html  in a browser. Most apps work this way.
  • Full features (opening DWG files, and the design apps' advanced tools)
    need the files to be *served*, not opened directly. Run one of:
        macOS   : double-click  serve.command
        Windows : double-click  serve.bat
        Linux   : ./serve.sh
    …then use the page it opens at  http://localhost:8000

OPENING FILES
  • Click "Open file…" on the home screen, or drag a file onto the window.
    Essentials sends it to the right app automatically:
        .docx .xlsx .pptx .pdf .eml …  → Bureau office apps
        .dxf .dwg .lwk                 → Linework CAD
        .psd .png .jpg / .svg .ai      → Pixel / Vector
  • DWG files are converted on open via LibreDWG (served/desktop mode).
  • You can also use each app's own Open menu.

Everything runs locally on your machine. Nothing is uploaded.
